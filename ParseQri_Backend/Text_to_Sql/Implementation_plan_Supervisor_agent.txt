Parseqri – Supervisor Agent Implementation Plan

(Local Ollama, Latency-Optimized, Production-Safe)

1. Objective

Implement a Supervisor (Orchestrator) Agent that:

Coordinates all Parseqri agents

Uses Ollama-available models

Minimizes model load/unload latency

Improves SQL accuracy and reliability

Prevents hallucination and uncontrolled agent behavior

2. Models to Use (FINAL)

Use only two models to avoid Ollama thrashing.

Purpose	Model
Supervisor, Intent, Schema, Response	dolphin3:8b
SQL Generation & SQL Validation	deepseek-coder:6.7b
Ollama setup
ollama pull dolphin3:8b
ollama pull deepseek-coder:6.7b

Create a single mutable state object.

Rules

4. Supervisor Agent Responsibilities

The Supervisor:

Decides which agent runs next

Enforces retry limits

Switches models intelligently

Terminates safely on failure

Never generates SQL or answers

5. Supervisor Execution Flow (Deterministic)
1. Run Intent Classification (dolphin3)
2. If intent confidence < 0.70 → retry once
3. If still < 0.70 → exit with clarification request
4. Run Schema Filtering (dolphin3)
5. Run SQL Generation (deepseek-coder)
6. Run SQL Validation (deepseek-coder)
7. If validation fails:
     - increment sql.attempts
     - retry SQL generation (max 2 attempts)
8. If SQL valid:
     - execute SQL in code (not LLM)
9. Run Response Formatting (dolphin3)
10. Return final response

6. Supervisor Pseudo-Code
def supervisor(state):

    run_intent_agent(state, model="dolphin3:8b")
    if state["intent"]["confidence"] < 0.7:
        run_intent_agent(state, model="dolphin3:8b")

    if state["intent"]["confidence"] < 0.7:
        return "Please clarify your request."

    run_schema_agent(state, model="dolphin3:8b")

    while state["sql"]["attempts"] < 2:
        run_sql_generation_agent(state, model="deepseek-coder:6.7b")
        run_sql_validation_agent(state, model="deepseek-coder:6.7b")

        if state["validation"]["is_valid"]:
            break

        state["sql"]["attempts"] += 1

    if not state["validation"]["is_valid"]:
        return "Unable to generate a valid SQL query."

    execute_sql_in_code(state)

    run_response_agent(state, model="dolphin3:8b")

    return state["final_response"]

8. SQL Hardening (MANDATORY)

Add code-level validation before accepting SQL.

Checks:

SQL parses successfully

Tables exist

Columns exist

GROUP BY correctness

No SELECT *

If any check fails:

Mark validation as failed

Retry SQL generation

Recommended libraries:

sqlglot or sqlparse

9. Latency Optimization Rules

Group calls by model

Do not interleave models unnecessarily

Use low context for Supervisor

# Supervisor
OLLAMA_NUM_CTX=2048

# SQL agents
OLLAMA_NUM_CTX=4096
